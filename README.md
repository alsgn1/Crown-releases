# Crown

MacBook 노치에서 음악, 파일, 집중 타이머, 배터리를 바로 보고 조작하는 macOS 앱이에요.
이 저장소에는 설치 파일과 업데이트 정보만 있어요.

## 설치

1. [최신 버전](https://github.com/alsgn1/Crown-releases/releases/latest)에서 `Crown-버전.dmg`를 받아요.
2. dmg를 열고 Crown을 Applications 폴더로 끌어다 놓아요.
3. 처음 열 때 경고가 뜨면 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 [그래도 열기]를 눌러요. (macOS 14는 Crown을 오른쪽 클릭 → [열기])

macOS 14 이상에서 동작해요. 한 번 설치하면 새 버전은 Crown이 알아서 받아서 설치해요.

`appcast.xml`은 Crown이 새 버전을 확인할 때 읽는 서명된 파일이에요.
